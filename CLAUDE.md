# Exosomes Global Naive Market Dashboard

## What this is
A dashboard tracking current market entry points for naive MSC-derived exosomes
in global markets. Built for NurExone Biologic Ltd.

## Structure
- market_dashboard_v2.py — current active version
- market_dashboard.py — older version (to be reviewed/archived)
- dashboard.html — standalone HTML version
- data/ — market data files (signals.csv, meta.csv)
- scripts/ — utility scripts
- requirements.txt — Python dependencies
- .devcontainer — dev container config
- .github/workflows — CI/CD workflows

## Tech stack
Python, Plotly/Dash (confirm), HTML
